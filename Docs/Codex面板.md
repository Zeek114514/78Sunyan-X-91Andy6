# 在 Unity 里使用小猫开发助手

项目：`D:\Projects\VoxelDemo-Unity`。

## 打开

1. 切到 Unity，等待新脚本导入和编译完成。如果正在 Play，先停止。
2. 顶部菜单选择 **VoxelDemo → Codex 聊天**。
3. 把窗口标签拖到 Inspector 或 Project 旁边，就可以停靠在编辑器内。
4. 点击 **连接**。本机已有 Codex 和 ChatGPT 登录时，会直接复用。若提示未登录，点击 **登录 ChatGPT**，在浏览器完成授权。
5. 输入需求，点击 **发送**，或按 **Ctrl + Enter**。连接断开时按钮显示 **连接并发送**，点击会自动重连；未登录时先完成登录，再发送。

例如：“解释一下世界怎么生成”“帮我分析附上的报错”“把跳跃高度调高一点，其他玩法保持不变”。

## 发图片

- **截图粘贴**：截图后，在面板里按 **Ctrl+V**，或点击 **粘贴图片**。
- **拖入**：把资源管理器或 Unity Project 中的 PNG/JPG 图片拖进聊天面板。
- **选择文件**：点击 **添加图片**，选择电脑上的图片。

看到输入框上方的缩略图才表示附件已添加。点击缩略图可放大预览，点击“×”可移除；输入问题后发送，也可以只发图片。助手会收到真实图片内容，而不只是一个文件路径。聊天记录中的图片也可以点击查看。

每条消息最多 8 张，单张不超过 20 MB，目前支持 PNG、JPG/JPEG。图片副本保存在 `Library/CodexPanel/Attachments`，不会放进 Assets，也不修改原图。删除 Library 后本地缩略图缓存会丢失。仅查看图片不需要勾选“允许修改当前项目”。

普通文字的 Ctrl+V 仍然是文字粘贴。此版本的剪贴板图片功能适用于 Windows；只在你触发粘贴时读取剪贴板，发送前不会把图片交给模型。

## 修改代码

默认可以讨论和读取项目。需要修改代码时，勾选 **允许修改当前项目**，再发送任务。常规项目内改动会直接进行；额外的执行或文件权限请求会显示在面板里，查看内容后选择“允许这一次”或“拒绝”。

在 Play 模式里，不勾选“允许修改当前项目”即可直接讨论、发图片。需要改代码时，按钮显示 **停止试玩并发送**；点击后会停止 Play、等待重载、重连并发送，文字和图片会保留。准备期间可以取消，连接失败也会保留草稿。编译或处理消息期间，输入框下方会说明暂时不能发送的原因。

回复过程中可点击 **停止**。关闭窗口或在编辑模式切换到 Play 时，面板会断开自己的连接和本地任务进程，不会关闭你的 Unity 或桌面 Codex。停止和断开不会自动撤销已经写入的文件，可用 Git 检查和还原。

任务执行期间会暂缓自动资源刷新和脚本重载，结束后恢复，避免代码修改到一半时 Unity 重新编译。完成后查看 Console 的编译结果，并实际点 Play 验证效果。

## 给助手提供上下文

- **附上选中对象**：把当前场景、选中资源路径和组件名称放入输入框。确认后再发送，不会自动保存场景。
- **附上最近报错**：把面板打开后记录的最近报错放入输入框；可以编辑后再发送。
- **新对话**：在面板中开始一段新的会话。旧的服务器会话不会因此被删除。

这个面板有自己的会话，不会自动完整搬入桌面聊天历史。助手会读取项目的 AGENTS.md 和相关代码，已经配置为用简洁中文交流，并保留小猫助手的称呼。

## 登录、记录与模型

使用官方 Codex App Server，通过本机 `codex.exe` 连接。没有新增 API 密钥输入框，也不把登录凭据复制到 Assets 或提交 Git。使用量及可用模型受当前 Codex 账号和配置约束，不保证与桌面聊天使用相同的模型。

项目内最近 200 条显示记录和会话标识保存在 `Library/CodexPanel/session.json`，不进入 Git。删除 Library 后这些本地显示记录会丢失；不会因此删除 Codex 服务端会话。对话正常发送给 Codex 服务处理，不是离线聊天。

Codex 升级后若连接失败，打开面板 **设置 → 自动查找**；也可手动选择 `codex.exe`。不需要填写账号密钥。

## 检查与维护

菜单 **VoxelDemo → Codex 连接自检** 可执行一次真实连接测试，会使用少量账号额度。它使用独立自检会话，检查项目代码读取、Temp 内写入、断开续聊和停止任务，不更改游戏脚本。通过后会归档自检会话。结果保存在 `Artifacts/CodexPanel/validation.json`，不进入 Git。

实现位于 `Assets/Editor/CodexPanel`，只运行在 Unity 编辑器内，不会进入打包后的游戏。新增的 Newtonsoft JSON 直接依赖固定为项目已经使用的 3.2.1，未升级引擎或渲染管线。

依据：[OpenAI Codex App Server 官方文档](https://learn.chatgpt.com/docs/app-server)。

图片功能自检：菜单 **VoxelDemo → Codex 图片自检**，会使用少量账号额度测试多图、纯图片消息和记录恢复。仅用测试色块图片进行模型识别；如剪贴板有图片，会在本机验证读取，不会把剪贴板内容作为测试图片发送。
